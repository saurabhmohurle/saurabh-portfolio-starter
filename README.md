# 🔐 Saurabh Cybersecurity Portfolio

This is my personal cybersecurity-themed developer portfolio, built using **React**, **Three.js**, **Framer Motion**, **Tailwind CSS**, and **tsparticles**. It showcases my projects, skills, and services in a modern, interactive format with 3D animations and glowing effects.

> **Live Site**: [Click here to visit](https://saurabhmohurle.github.io/saurabh-portfolio-starter/)

---

## 🛠 Tech Stack

- React
- Tailwind CSS
- Three.js + @react-three/fiber
- Framer Motion
- tsparticles
- gh-pages (for deployment)

---

## 🧪 Local Setup (Run Locally)

```bash
# 1. Clone the repository
git clone https://github.com/saurabhmohurle/saurabh-portfolio-starter.git

# 2. Go to the project folder
cd saurabh-portfolio-starter

# 3. Install dependencies
npm install

# 4. Start the development server
npm start
